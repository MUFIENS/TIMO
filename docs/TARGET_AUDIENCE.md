# Target Audience — Timo

## Audience strategy

Timo is designed for a broad audience, but the first version should prioritize people who use Windows computers regularly and can benefit from understanding mixed digital activities.

## Primary segments

### 1. Students

**Jobs to be done:** understand the balance between schoolwork, browsing, media, and games; notice long sessions; reflect on daily patterns.  
**Needs:** simple labels, easy-to-read summaries, no technical setup, friendly tone, no shame-based productivity score.  
**Design implication:** plain-language explanations, onboarding defaults, clear app icons/names, and accessible navigation.

### 2. Professionals and creators

Includes developers, designers, editors, freelancers, and office workers.

**Jobs to be done:** understand time spent in tools such as IDEs, design software, browsers, communication apps, and entertainment.  
**Needs:** trustworthy per-app history, date ranges, exportable data, accurate session boundaries, and useful timeline.  
**Design implication:** dense enough for analysis but visually calm; support keyboard navigation and fast filtering.

## Secondary segments

### 3. General desktop users

People who want a high-level view of their computer habits without knowing process names, file paths, or system terminology.

**Needs:** obvious navigation, readable typography, explainable categories, minimal setup, no mandatory account.

### 4. Older or less technical users

Not a separate product tier. They are included in the accessibility and usability target.

**Needs:** generous text sizing, clear labels, high contrast, predictable interactions, no icon-only navigation without accessible names, and reduced motion.

## Persona snapshots

| Persona | Context | Success outcome |
|---|---|---|
| Student | Uses laptop for lessons, assignments, browsing, and games | Understands how study and entertainment time are distributed |
| Creator | Switches among editor, browser, design tool, and media | Sees accurate time per tool and a useful timeline |
| Casual user | Uses PC for browsing, video, chat, and occasional games | Understands daily use without technical knowledge |
| Accessibility-conscious user | Needs readable and predictable UI | Can navigate and understand all key information |

## What Timo must not assume

- A long session is automatically bad.
- A game is automatically harmful.
- Browser time is always productive or always entertainment.
- The person behind the Windows account is necessarily the person currently using the PC (shared devices exist).
- A user's age, ability, job, or intent can be inferred from application usage.

## Research questions for later usability tests

1. Do users understand the difference between active app time and idle time?
2. Do category names make sense to non-technical users?
3. Can users correct an unknown app without assistance?
4. Do users understand that Timo tracks applications but not browser pages or content?
5. Is the mascot reassuring rather than distracting or childish?
